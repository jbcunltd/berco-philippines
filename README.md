# Berco — the-heart-of-your-home

Public website for **Berco**, custom cabinetry & interiors under JBC UNLTD CORP (Philippines).
Live at **https://berco-philippines.vercel.app** · Tagline: *The Heart of Your Home.*

- **Stack:** Next.js (App Router), Libre Bodoni + Jost self-hosted via `next/font`
- **Deploys:** automatically to Vercel on every push to `main`
- Imagery is warm "design reference" placeholders until real project photos are added.
